# D3 — Tauri + Rust core; React + Vite + TypeScript + Tailwind; xterm.js

**Date:** 2026-07-28 · **Status:** Committed

## Context
Needed: PTY handling, git, filesystem watching, subprocess supervision, and a
desktop UI dense enough for tabs, trees, diffs, and later a sprite character.

## Decision
Tauri with a Rust core. React + Vite + TypeScript + Tailwind for the UI.
xterm.js for the terminal.

## Rationale
- Rust gives PTY, git, and file watching natively — no second runtime.
- Tauri is the proven pattern here; Professor already ships on it, so the build,
  packaging, and webview quirks are known territory rather than research.
- React has the deepest agent training coverage of any UI framework, which
  matters directly when the app is being built *with* agents. This is a
  tooling-ergonomics argument, not an aesthetic one.

## Consequences
- Linux first. Windows and macOS follow the Tauri packaging path.
- Anything the webview cannot reach goes through a Rust command — Professor
  already hit this with local HTTP on Linux.
