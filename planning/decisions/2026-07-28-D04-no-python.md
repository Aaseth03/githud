# D4 — No Python, no UV

**Date:** 2026-07-28 · **Status:** Committed

## Context
The original capture assumed a Python backend. On examination that was an
assumption carried over from earlier attempts, not a requirement.

## Decision
No Python anywhere in GIT HUD. No UV.

## Rationale
PTY, git, and file watching are native in Rust. Voicebox is an external service
reached over REST. Once those two facts are true, nothing is left for a Python
layer to do except add a runtime to install, version, and package.

## Consequences
- Voicebox stays external and is supervised over HTTP, never imported.
- Any future need for Python must reopen this record rather than sneak in as a
  script.
